# Provenance and licensing

SAID source code is Apache-2.0. The model also depends on upstream OpenAI CLIP/LongCLIP/SmartCLIP code and weights, whose notices and terms must accompany redistribution. DOCCI, DCI/Long-DCI, Flickr30k, COCO and ShareGPT4V have separate dataset terms. This release does not grant rights to those datasets or guarantee that a trained derivative may be publicly redistributed. The intended repository therefore remains private until the owner confirms rights and access policy.

No API token, raw image, training annotation or server credential belongs in the repository. Verify every downloaded artifact against `CHECKSUMS.sha256`.
