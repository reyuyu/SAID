# C1 micro ablation：最终报告

本轮基于 C1-TCR 的共同初始化，只研究 U 重建输入与视觉重建梯度开放方式。A=C1-UN，B=C1-VWarm；未运行组合版或其他算法。

## 训练与选型

A 与 B 各完成 250 optimizer steps，固定同一训练数据流、global matching batch=1024、原 C1 SmartCLIP 目标、lambda_rec=1、3651-step LR horizon。开发集为预先存在的固定 1000 图×5 caption manifest，仅用于选型。

| 候选 | 开发集 I2T R@1 | 开发集 T2I R@1 | J_dev |
|---|---:|---:|---:|
| C1-UN@250 | 89.4% | 87.1% | 88.25%
| C1-VWarm@250 | 89.3% | 87.2% | 88.25%

两者并列，按预先规则选择结构更简单的 C1-UN。随后从其真实 250 步 checkpoint 恢复到 500 步；日志确认恢复游标为 250，没有从 batch 0 重新标记。

## 最终 native CLS/EOS 检索

| 实验 | COCO I2T R@1/5/10 | COCO T2I R@1/5/10 | Urban-1k I2T R@1/5/10 | Urban-1k T2I R@1/5/10 |
|---|---|---|---|---|
| S0@500 | 60.58 / 82.20 / 89.06 | 41.236 / 67.092 / 76.62 | 87.0 / 97.1 / 98.8 | 84.2 / 96.7 / 98.1 |
| C1@500 | 60.38 / 82.48 / 88.80 | 41.216 / 67.188 / 76.644 | 87.0 / 97.3 / 99.1 | 83.7 / 96.3 / 98.1 |
| C1-UN@500 | 60.50 / 82.36 / 88.92 | 41.356 / 67.18 / 76.66 | 86.8 / 97.2 / 98.8 | 84.2 / 96.3 / 98.3 |

与 S0@500 的全精度差值：COCO I2T R@1 = -0.0008，T2I R@1 = +0.0012；Urban-1k I2T R@1 = -0.0020，T2I R@1 ≈ 0。COCO 正式门要求 I2T≥0.6058 且 T2I≥0.41236，C1-UN 的 I2T 未达到，因此结果为 **NOT PROMISING_AT_500**。

主评估只使用原生 CLS/EOS；没有使用 decoder、teacher 或 fine-grained reranking。最终比较只包含 COCO 和 Urban-1k。
