\paragraph{Implementation Details.}
We initialize Sema-CLIP from the OpenAI CLIP ViT-B/16 or ViT-L/14 checkpoint. Both encoders use 224$\times$224 RGB images with CLIP bicubic resize, center crop, and channel normalization. ViT-B/16 has $16\times16$ patches (196 patch tokens plus CLS), while ViT-L/14 has $14\times14$ patches (256 patch tokens plus CLS). Text is tokenized with the repository's OpenAI CLIP BPE tokenizer and a 248-token context (including start/end tokens). During training, a one-layer mask Transformer and attention pooling produce text and visual conditions. The BalancedStack fusion uses
\[
g=\sigma(W_t t+W_v v),\qquad z=g\odot t+(1-g)\odot v,
\]
with a zero-initialized gate and a Xavier-initialized visual adapter. The visual patch input to this auxiliary branch is detached as in the released implementation. At inference, we export the student CLIP and retrieve with its native full-image and full-caption embeddings; mask and fusion modules are not used.

Training uses ShareGPT4V after the deterministic removal of the first 1,000 records (1,245,901 records remain). Captions are whitespace/newline normalized, split on ``. ``, and truncated to the longest prefix fitting 248 tokens. We construct full ($F$), all-detail ($D_{\rm all}$), and deterministic nested detail ($D_3$) views; $D_3$ uses the SHA256-derived sampler with seed 0. We train with four NVIDIA A100 80GB GPUs, 256 examples per rank (global batch 1024), eight workers per rank, and seed 0. AdamW uses $(\beta_1,\beta_2)=(0.9,0.999)$, $\epsilon=10^{-8}$, weight decay $10^{-2}$ for the backbone and zero for mask/adapter groups. Peak learning rates are $10^{-6}$ (backbone), $10^{-3}$ (text and visual masks), and $2\times10^{-4}$ (fusion adapter). BF16 autocast and encoder gradient checkpointing are enabled.

The symmetric image-to-text/text-to-image contrastive objective uses view weights $[1.35,1.35,0.30]$, sparsity weights $[1,2,2]$, HNS coefficients $[2,2]$, and a linear 200-update HNS ramp. Ordinary inclusion loss is disabled. The ViT-B/16 full follow-up uses horizon 4868 (the paper node is step 3651); ViT-L/14 is trained independently for five epochs, 6085 updates, with horizon 6085. Evaluation uses full candidate-pool cosine retrieval with L2-normalized native embeddings on COCO-Val5K, Flickr30k-Test1K, DOCCI, reconstructed 7602-pair Long-DCI, and Urban-1k; Flickr30k-Full is reported separately under its 31,783-image/158,915-caption protocol.
