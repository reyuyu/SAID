## 实际验证

被测合并代码：`93a8010`；后续编辑仅涉及文档及证据。测试在原服务器独立临时目录内执行，使用 Python3.10 / PyTorch2.5.1+cu124，CPU/Gloo，不占用训练 GPU。

```bash
CUDA_VISIBLE_DEVICES='' GLOO_SOCKET_IFNAME=lo OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 \
  /root/miniconda3/envs/said-smartclip/bin/python -m pytest -q \
  tests/test_dual_mask_suffix.py tests/test_dual_mask_suffix_full_v01.py \
  tests/test_dual_mask_suffix_resume.py tests/test_extended_retrieval.py
```

第一次结果：36 passed、2 failed、退出1。两项失败都是临时目录缺少默认相对训练数据路径，堆栈为 `FileNotFoundError`。指定真实数据根目录后仅重跑这两项：

```bash
SHARE4V_DATA_ROOT=/root/datasets/ShareGPT4V \
  CUDA_VISIBLE_DEVICES='' GLOO_SOCKET_IFNAME=lo OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 \
  /root/miniconda3/envs/said-smartclip/bin/python -m pytest -q \
  tests/test_dual_mask_suffix_resume.py::test_dry_item_matches_the_real_item_and_the_rng_state_on_real_data \
  tests/test_dual_mask_suffix_resume.py::test_dry_placeholder_is_collate_compatible
```

第二次：2 passed、退出0。合计38项相关检查通过，包括小模型生产 DDP 总目标、Full 参数设置、续训和检索指标测试。没有放宽容差。两次运行均有现有 `pkg_resources` 弃用警告。原始输出：[第一次](main_sync_evidence/pytest_initial.json)、[数据路径修正后的两项](main_sync_evidence/pytest_data_paths.json)。

README 中的 Python 示例也用真实 Full step2000 bare student 在 CPU 执行：严格加载317张量；score shape 为1×2；两项得分均有限；退出0。只把示例中的 checkpoint 路径替换为已校验文件，未使用额外 gate 评分。原始输出：[README smoke](main_sync_evidence/readme_smoke.json)。
