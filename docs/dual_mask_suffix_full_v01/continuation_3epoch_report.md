# Dual-Mask-Full v0.1 续训到满 3 epoch 的结果（`10*L_S + 2*S_S + 10*L_U + 2*S_U`）

**arm**：`S0_DUALMASK_FULL_V01`　**分支**：`codex/s0-dualmask-full-v01`
**续训 SHA**：`873b43a5bc000528311e22aac01e92045ac898e0`（从此前 500 步 run 的 SHA `dcd33877…` 严格续训）
**目标函数代码**：`model/dual_mask_suffix.py` sha256 `e92232b78511c53612a4eec9ebc7fea1302f60c397eba53c81fba0b9c12ff630`（与 500 步训练时**逐位相同**，`git diff` 为空）
**预算**：从共同初始化的 500 步检查点续训到 **3651 次更新 = 3 × 1217 = 整个 cosine horizon（3 epoch）**
**评估**：仅评 **3 epoch（3651）**；2 epoch 的 2434 步没有检查点（存点间隔 500），按用户指示**不补跑、不评**。

## 0. 一句话结论

**继续训到满 3 epoch 确实让这个组合消融变好，但没有改变它的性质。** 相对它自己的 500 步：COCO I2T **+0.640 pp**、T2I **+0.080 pp**（几乎不动），Urban I2T **+3.400 pp**、T2I **+2.900 pp**。
到 3 epoch 时，**COCO 两个方向仍然低于 S0@500**（−1.160 / −0.940 pp），更明显低于 S0@1000（−2.300 / −1.696 pp）；而 **Urban-1k 是本族里最好的**：I2T **0.9180**、T2I **0.9070**（比 S0@1000 高 **+2.800 / +5.200 pp**）。**"COCO 掉、Urban 涨"的方向分裂在更长训练下没有被抹平，反而更清楚。**

## 5. 限制与不做的事

* **组合消融**：后缀对齐权重（1→10）与 U 稀疏（0→2）同时改变，结果不能单独归因于任一项；本轮**未跑单因素臂**。
* **更长训练不是"修复"**：500 步与 3 epoch 两个预算并列报告；3 epoch 的 COCO 仍低于 S0，因此不能读成"再训久一点就好了"。
* **未运行 native 正式对照**，也没有重训任何既有基线；**2 epoch 未评**（无该检查点）。
* **单 seed**；不声称跨 seed 稳定，也没有把 run 间差值当作波动上限。
* **内容级数据流未获独立验证**（见 §2 末）。
* 门统计（keep ratio / 全开 / 全关 / cos）只是描述量，**不等于**语义纯度或"更纯净的 Unsaid"。
* 未评中间检查点（1000–3500 已保存）；未做参数搜索、未续训到 3651 之外。
