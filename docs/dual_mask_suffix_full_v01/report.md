## 0. 一句话结论

**把后缀对齐强度从 1 提到 10、并新增有效正配的 U 门稀疏项（权重 2）之后，COCO 原生检索明显下降、Urban-1k 反而上升，冻结晋级门判定为 FAIL。**
COCO I2T R@1 **0.5878**（比 S0@500 低 **1.80 pp = 90 个图像查询**，比旧弱后缀双MASK@500 低 **1.76 pp = 88 个查询**）；
COCO T2I R@1 **0.40216**（比 S0 低 **1.02 pp = 255 个文本查询**，比旧弱后缀低 **1.248 pp = 312 个查询**）；
Urban-1k I2T R@1 **0.8840**、T2I R@1 **0.8780**，比 S0 高 **+1.40 / +3.60 pp**（+14 / +36 个查询），比旧弱后缀高 **+0.20 / +2.00 pp**。
这是**两因素同时改变**的组合消融：后缀对齐权重与 U 稀疏项一起变了，**不能把结果单独归因于其中任何一个**。

## 1. 唯一的目标函数改动

```
旧：L_old  = 10*L_S + 2*S_S + 1*L_U
新：L_full = 10*L_S + 2*S_S + 10*L_U + 2*S_U
```

四个系数从第 1 步起固定，无 loss warmup、无动态调权、无梯度平衡，总 loss 外不再乘任何因子。
`S_U = (1/V) * Σ_{i: valid_i} mean_d(abs(m_U[i, i, d]))`，只取**有效正配**（局部行 `a` 的全局正配列是 `rank*B + a`），
`mean_d` 只除一次 `D=512`，用的是 live Hard-ST 门与 `abs` 约定（关闭门在 0 处次梯度为 0）。
实现、正配抽取与 DDP 归约细节见 `docs/dual_mask_suffix_full_v01/README.md`；代码改动只落在
`model/dual_mask_suffix.py` 与 `train/train_dual_mask_suffix.py`（新增 `--lambda-suffix`、`--lambda-u-sparse`，默认值 1.0/0.0 即旧版逐位行为）。

**DDP 归约（已实测）**：单进程本地反传值是 `(W/V) * Σ_local`，日志值是正确归约的 `Σ_global / V`。
第 54 步实测：`loss_u_sparse_global = 1.0`、加权 `2.0`、本地反传 `1.0078 = (4/770) × 194`（该 rank 的有效数 194），
与规格预测（初始化全开时全局应为 1、加权应为 2）完全一致。

## 2. 测试（20 项全通过）

* `tests/test_dual_mask_suffix.py`（**未改动的旧测试**，10 项）：旧配置（1.0 / 0.0）回归，含两进程 DDP 总目标对照 —— **全部通过**，即默认路径与 `ff5ad1d4` 行为一致。
* `tests/test_dual_mask_suffix_full_v01.py`（新增 10 项）：
  1. 新权重确实进入总 loss，S0 部分逐位不变，`L_U` 不随稀疏权重变化，`loss_total = 10L_S+2S_S+10L_U+2S_U` 成立；
  2. 初始化全开时 `S_U = 1`、加权 2，新旧总 loss 之差恰为 `9L_U + 2`；
  3. 正配稀疏索引：非方形瓦片／跨瓦片尾部／非连续 valid 与未分块参考一致，计数等于有效数，改动非正配列不改变 `S_U`；
  4. 稀疏梯度与独立 `abs(hard-ST(sigmoid(logits)))` 参考逐元素一致，只到新门（图像/文本特征无梯度），全关门时 `S_U=0` 且门参数无梯度；
  5. `(W/V)·Σ_local` 与 `Σ_global/V` 的归约语义；
  6. 两个新系数可存读回、完整 F 严格加载、裸学生只含 CLIP state。
* 两进程 DDP 对照已扩展到新目标（`--lambda-suffix 10 --lambda-u-sparse 2`）：小模型 + 非全开门，覆盖 valid 1 vs 3、零有效 rank、`V<2`，逐参数比较梯度与一步更新，并校验 `S_U` 全局值与本地反传值。

## 6. 哪些结论成立、哪些不成立

**直接测量（可信的读数）**：上表所有 R@1/5/10；500 次更新与 512,000 次呈现；四 rank 流摘要逐位相同；每卡 67.42 GiB；门轨迹与分组梯度范数；导出/加载的无损性与退出码。

**机制观察（与假设相容，但不是因果）**：
* 500 步时后缀项占本地反传总损失约 **79.5%**（旧 run 约 29.9%），主干梯度范数约为旧 run 的 1.8×/2.4× —— 与"原生对齐在总信号中的份额被挤压"相容。但这是**数值损失份额**加上**求和后目标的分组梯度范数**，两者都不是分项梯度分解。
* COCO 掉分、Urban 涨分同时出现：**方向相反**，所以这不是"方法整体变差/变好"的单向结论；两套协议的原生读出对同一模型给出不同排序。
* 新增的 U 稀疏项并没有把门关得更多（全 pair keep 0.9719 略高于旧 run 的 0.9610），但 `p` 均值更低（0.7372 vs 0.7673）、全开正配比例降到 26%、**没有任何正配被全关**。

**不能归因的部分（明确未检验）**：
* **组合消融**：后缀对齐权重（1→10）与 U 稀疏（0→2×）同时改变，无法把掉分/涨分拆给其中任一项；没有跑单因素臂。
* **数值权重 ≠ 梯度范数**：四个系数只是数值；分项梯度贡献没有被分解测量（分组范数来自求和后的目标）。
* **关闭更多坐标 ≠ 提取了更纯净的 Unsaid**：本轮没有任何 Unsaid/语义纯度测量，门统计只是描述量。
* **未运行 native 正式对照**，也没有重训任何既有基线。
* **单 seed**：不声称跨 seed 稳定；也没有把两次 run 差值当作随机波动上限（旧弱后缀与本轮是不同目标，不是同一配置的重复 run）。
* 协议桥接只证明"评估协议一致（R@1 逐位相同）"，**不证明**两套评估器的浮点路径完全相同。
