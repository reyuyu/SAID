## 0. 一句话结论

在 128 图文池上，**"文本表征变化量大"与"该变化影响检索判别"几乎脱钩**（变化量前 32 与 |margin| 前 32 只重合 5–8 个坐标），判别作用高度集中在极少数坐标（#442 一项就占全部 |margin| 的 ~9%）；在 5 个受控裁剪场景上，**图像删对象与文本对象变化只构成"弱相容"方向**（cos(dv,dt) 均值 0.08–0.11，2/5 场景符号相反）；**本轮没有证据表明 SmartCLIP 的坐标 mask 更能区分"删未述对象"与"删已述对象"**（正确偏好比例与原生一样是 3/5，两种口径下的次序统计也都不占多数）；坐标 vs 子空间的描述性事实是"变化不沿少数原始坐标分布"，但**这不足以支持"换成子空间投影就会涨分"**。

## 3. 方法（可核对的口径）

### 3.1 逐坐标 margin 归因（阶段 A）

对每个后缀条件 `R`（R1–R4，在 caption 后追加一句**与图像内容无关**的句子）与每个查询 `i`：

- 分数 `Q = 100 · V̂ · T̂ᵀ`（`F.normalize(eps=1e-6)`），I2T 与 T2I **分别**计算。
- `ΔQ_i = Q(BASE) − Q(R)`；逐坐标贡献 `c_d(i) = 100 · v_i,d · ΔT_R,d`，并核验 **Σ_d c_d(i) = ΔQ_i**（恒等式残差逐条件报告）。
- **固定负例**口径：以 BASE 下最强负例 `j*` 为固定负例，`margin 贡献 = 100·(v_i − v_{j*})_d · ΔT_d`，核验 Σ_d = 实测 margin 差；同时报告"最强负例被切换"的查询数（因为切换后固定负例口径不再等价）。
- 排名规则显式定义：`rank = 1 + #{j : score_j > score_pos 或 (并列且 id_j < id_pos)}`（**按 id 破并列**，不用浮点相等）。
- 相似度对照用**真 Jaccard** `|∩|/|∪|`，并另给 `overlap_at_k = |∩|/k`（两者不混用）。
- 共同偏移：`mu_R = mean_j ΔT_R[j]`，I2T 中 `100·v_i·mu_R` 是整行常数；核验扣除后**逐查询排名不变**；T2I 不自动成立（图像侧逐查询不同），单独声明。
- 候选池二次型：`ΔT_jᵀ C_V ΔT_j` 与"该文本变化对当前候选池的未乘 100 分数方差"对照（协方差恒等式）。
- 尺度控制：`Q×{0.5, 1, 2}`，看排名是否变化（区分"排序"与"CE/熵"）。

### 3.2 坐标 vs 子空间（阶段 A 附带）

把前半样本的 ΔT 做 SVD，按**同等秩预算**比较：k 个原始坐标捕获的能量 vs k 个方向（子空间）捕获的能量，在**后半样本**上评价（样本外）；未中心化与中心化各一份。

### 3.3 受控裁剪场景（阶段 B）

- 从 COCO val2017 instances 里按固定几何规则挑**两个对象**：每个对象框 ≥ 画布 2%、空间可分、并有合法的同尺寸控制裁剪。
- 四视图：`I_AB`（完整图 224²）、`I_A`（只留 A）、`I_B`（只留 B）、`I_control`（同尺寸控制裁剪），全部经**同一官方预处理**（`Resize((224,224))` + CenterCrop + ToTensor + Normalize，且解析映射与 pipeline 一致，5/5 场景核对为真）。
- 记录：目标/他者在各视图的**框级保留率**、**分割点多边形点保留率**、四视图 sha256、裁剪框坐标、每场景四视图联系图 PNG。
- 四分数恒等式：`K = 100·(v(I_A) − v(I_B))·(t(T_A) − t(T_B))`，并核验其等于由四视图×三模板分数拼出的同一量；同时导出逐维 `K_d` 与正/负能量。
- SmartCLIP 条件选择：对 T_A 生成**一次** mask `m_A`，四个视图**共用同一个 `m_A`**（`z = Norm(v(I)⊙m_A)`）；T_B 对称。因此没有把正确 caption 的 mask 泄漏给整行负例，也因此**不对 masked 读出声明单点 `dv·dt` 恒等式**。
- 删除口径（本报告的核心更正点，见 §7）：`Δscore = score(I_AB) − score(删该对象视图)`，删未述 B 用 `I_A`、删已述 A 用 `I_B`；**有符号均值与绝对均值分别报告**。

### 3.4 旧探针错误的修正（本轮落实）

改述（paraphrase）机制化审计、I2T/T2I 双向分离、离散配对结果（不用 p 值墙）、Jaccard 命名、EOT 有效长度（`argmax(token ids)+1`，绝不数 `token_id != 0`）、共同偏移比较用 −inf 掩码（不是把对角线清零）。改述审计 **12/12 通过**：`paraphrase_ok=true`、无颜色/数量被引入、无锁定概念缺失；后缀内容校验：**未进入编码器的后缀 0 个**、最大有效长度 33 ≤ 248、无截断。

| 量 | S0@500 | 初始化 |

## 6. 六个问题的回答

1. **非视觉表达造成的大位移，有多少影响候选区分？**
   影响**方向不对称且与位移量脱钩**。后缀造成的文本位移不小，但 I2T 上 S0 掉 6.25 pp 而 T2I 反升 0.78 pp，初始化正好相反（I2T 0.00、T2I −7.03 pp）；逐查询看只有 36–46/128（S0）的最强负例切换；"变化最大的 32 个坐标"与"判别作用最大的 32 个坐标"只重合 **5–8 个**；贡献集中在 **#442**。**大部分位移不改变排序。**

2. **哪些坐标变化反复帮助/损害正确 margin？**
   集中在 **#442**（S0 5.54 / 初始化 7.00，是第二名的 3.65× / 2.63×，占 |margin| 总和 9.0% / 8.7%），其后 #362、#481/#376、#96/#376 等，两模型共享同一主导坐标（同源初始化）。**必须同时说明**：正负贡献几乎对半（253/259、284/228），有符号均值只剩 −0.0073 / −0.0043（比逐坐标幅度小 4.4× / 7.2×）；这些是**当前 128 候选池上的代数归因**，不等于单维纯语义，也不等于"删维再归一化"的因果效果（未做）。

3. **图像裁剪与文本对象变化是否形成对应判别方向？**
   **弱相容**：四分数恒等式成立（≤5.7e−6），3/5 场景 K>0，但 cos(dv,dt) 均值仅 0.08–0.11、2/5 场景符号相反，两项正确 margin 常不同号。裁剪同时改变内容/位置/尺度/上下文（控制裁剪本身就把分数改变 0.50–0.61），且分割点保留率显示框内并非像素纯净 → **不能**把 K 读成"对象身份"的纯净跨模态方向。

4. **SmartCLIP 是否更能区分"删未述对象"和"删已述对象"？**
   **本轮没有支持**。masked 与原生 A 视图偏好同为 3/5（无改善）；"删未述扰动更大"只在一种口径下成立且脆弱（有符号 −2.75 vs −2.22，|Δ| 则 7.34 vs 2.93，且被单场景 −12.8 主导）；逐场景符合期望次序 2/5（有符号）或 1/5（|Δ|）。n=5 不足以判定，mask 保留频率与判别贡献坐标几乎不相关（Pearson 0.009–0.024）。

5. **模态间隙相关坐标是否也参与判别？**
   部分参与但**相关被单点驱动**：gap² 与 |margin| 的 Pearson 0.88–0.89、秩相关仅 0.25–0.29，top32 重合 15–18/32 → 典型坐标上关系很弱，Pearson 几乎完全来自 #442。故只能说：部分大间隙坐标（尤其 #442）确实参与判别，但"间隙大 ⇒ 有用/无用"都不成立。本轮只测简单 mean/centroid gap，**没有实现也没有复现 RMG**，无因果结论。

6. **当前证据是否支持"坐标选择过于受限"？还缺什么证据？**
   **描述性地支持**"变化不是沿少数原始坐标"：同等秩预算下 k=16 个方向在后半样本捕获 66.7–81.2% 能量，而 k=16 个坐标只捕获 15.4–18.9%（中心化 18.8–18.9%）。**但不足以支持"改用子空间投影就能涨分"**：本轮只测能量捕获，未训练投影头、未做删方向后的检索搜索，未中心化方向还含共同偏移。缺的证据：① 样本外真正做一次"投影/删方向 → 重新评测 R@1"的对照；② 更多裁剪场景（5 个太少）与像素级隔离；③ mask 与判别贡献坐标之间是否存在可训练的系统对应。
