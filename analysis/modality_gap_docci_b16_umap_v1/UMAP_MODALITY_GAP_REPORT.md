# DOCCI Modality Gap：固定参数 UMAP 重测

这次分析只使用已有 DOCCI 1000 对特征，没有重新加载模型、训练或改变样本顺序。输入为上一轮已经核验的 `features.npz`，包含 Long-CLIP、Ours Masked、Ours Native 在 Full、50% Prefix、First Sentence 三种 caption 设置下的 512 维 image/text 特征。

UMAP 参数固定为 `n_neighbors=30`、`min_dist=0.15`、`metric=cosine`、`random_state=0`、`transform_seed=0`。每个模型单独拟合一套 UMAP：该模型的三种 caption 设置和 image/text 特征合计 6000 个点共同拟合；不同模型之间没有共享 UMAP。50 条连线使用 seed=0 固定抽样的 50 个配对索引，具体索引保存在 `UMAP_PARAMS_AND_SAMPLES.json`。

## 结果文件

- `umap_main_2x3.pdf/png`：第一行 Long-CLIP，第二行 Ours Masked；列为 Full、50% Prefix、First Sentence。
- `umap_ours_native_1x3.pdf/png`：Ours Native 三种 caption 设置。
- `umap_quantitative_metrics.csv`：512 维原始空间指标、bootstrap 95% CI 和 2D 辅助连线长度。
- `UMAP_PARAMS_AND_SAMPLES.json`：UMAP 参数、bootstrap 参数、随机配对索引、特征/掩码来源哈希和软件版本。
- `UMAP_PROVENANCE.json`：输入实验 provenance 和输出清单。

## 图形观察

UMAP 没有消除图文双簇。Long-CLIP 和 Ours Native 中，文本点云仍集中在一个紧凑区域，而 image 点呈明显的外展结构；Ours Masked 则表现为更清楚的图像侧与文本侧分离区域。三种 caption 设置改变了局部形状和连线方向，但没有把两种模态变成一个混合簇。50 条配对线主要用于直观显示配对关系，不能用其 2D 平均长度推断 512 维模态差距。

与已有 PCA 图相比，UMAP 更容易展示局部邻域、分支和点云内部形状，但会对全局距离和簇间间隔作非线性重排；不同模型使用不同 UMAP，也不能比较跨行坐标距离。当前 DOCCI 结果里，PCA 对“是否存在双簇”和模型间的全局结构更直接，UMAP 对局部结构和配对线更有补充价值。因此论文主文建议保留 PCA 主图，UMAP 作为局部结构附图或诊断图。

## 限制

- 这是固定 seed=0、1000 对样本的描述性可视化，不能证明检索收益或因果关系。
- UMAP 的二维坐标只用于展示；所有模态 Gap 结论仍以 512 维指标和 bootstrap 区间为准。
- UMAP 谱初始化在部分拟合中报告 eigengap 不足并回退到固定随机初始化；参数、seed 和输入数据均未改变，该警告已保留在运行记录中。
- 公开 DOCCI 结果此前已被反复观察，不能据此宣称无偏泛化或新的 SOTA。
