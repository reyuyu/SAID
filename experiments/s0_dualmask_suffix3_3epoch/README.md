## 边界

原500步3/0未通过先前COCO保底选择规则，本次是用户明确要求的追加训练，不追溯修改先前选型记录。不同训练长度分开标注；不以单seed小幅分差宣称统计显著或最优。

续训实现按完成步数重放/跳过前500批，记录新阶段摘要。本次另外确认501–3651四rank数据摘要与本机Full同一数据流逐步一致，但不将其描述为训练器对全部被跳过历史内容的独立验证，摘要也不涵盖像素字节。

环境与初态沿用[500步实验](../s0_dualmask_suffix3_500/REPRODUCE.md)：本机重建容器与历史317个初始张量摘要一致，容器文件身份分别记录。Git包含代码、小型证据和10.2MB连续训练日志；模型、图片和完整标注未入Git，本包未发布可公开下载的模型附件。
