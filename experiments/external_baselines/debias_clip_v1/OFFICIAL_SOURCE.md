# Pinned official DeBias-CLIP source audit

Source: https://github.com/TRAILab/DeBias-CLIP, detached commit
`18a06c98bcb50018e22c3febca2aefc8c4a12e0d`, independent checkout
`/root/lk_projects/DeBias-CLIP-official`. Source Python/model/metric files remain unchanged.
The HTTPS shallow fetch used HTTP/1.1 after the initial clone timed out; checkout identity is verified.

[Official test script](https://github.com/TRAILab/DeBias-CLIP/blob/18a06c98bcb50018e22c3febca2aefc8c4a12e0d/scripts/test_script.sh)
has a backslash followed by a space after force-custom-clip, which breaks shell continuation.
Our expanded argv normalizes only shell syntax and machine-specific input/output paths:
model ViT-B-16-longclip, force-custom-clip, pretrained debias_vitb_3e.pt,
force-quick-gelu, eval-data base_full. Primary reproduction retains default AMP,
image batch1 and text batch16. No Python evaluation mathematics are patched.
An explicitly separate FP32 Urban diagnostic verifies the native adapter; it is not
substituted for the default-AMP published-score reproduction.

Model config: local_clip/model_configs/ViT-B-16-longclip.json. The official factory creates
CustomCLIP with LongCLIP vision/text types, 224 input, 512 joint width, 768 vision width,
512 text width, 12 vision/text layers and 248 positions. QuickGELU follows the test flag.
The factory stretches77 positions to248 using keep_length20 when loading original initialization.
The released checkpoint itself already contains both248x512 position tensors.
Its303 tensors and149835265 state tensor elements are recorded from the actual file.
The checkpoint contains epoch/name/state_dict/optimizer/scaler and no args/config.
Saved checkpoint name suggests OpenAI lineage; exact training flags are script provenance,
not asserted as independently saved checkpoint metadata.

Training script provenance only: 4 GPUs, batch64/GPU, global256, 3 epochs,
lr1e-6, wd0.01, eps1e-8, AdamW betas(0.9,0.999), warmup200,
local_loss/gather_with_grad, PCA32, short-loss fraction0.10, LongCLIP both,
keep_length20, DeBiasCLIP sampling, OpenAI pretrained initialization, QuickGELU.
No training was invoked.

Data parsing: Phase A uses raw official datasets and untouched training.data readers.
Urban captions.json is generated by the official helper with only two hardcoded path
assignments replaced in memory; directory enumeration and caption reading are unchanged.
The documented Flickr Karpathy source has a top-level images list, whereas the helper
expects a direct list and emits plural captions while read_flickr_pairs expects singular caption.
prepare_data.py adapts only this annotation schema and preserves all raw strings,
image filenames, split membership and within-split order. It never supplies a SAID manifest
as official-reproduction input. Dataset transfers and annotation fingerprints are audited.

Paper primary source: [arXiv2602.22419v2](https://arxiv.org/html/2602.22419v2), Tables3/4.
B/16 published I2T/T2I pairs: Urban93.1/93.0, DCI68.5/67.6,
Long-DCI57.8/57.4, DOCCI79.7/80.0, COCO61.3/43.0, full Flickr56.6/36.6.
Table5's last ablation row labels DOCCI T2I79.7 while the primary table/README give80.0;
this source inconsistency is retained, not resolved by choosing whichever matches our scores.
No aggregate mixes these published protocols.
