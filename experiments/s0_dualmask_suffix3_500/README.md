# S0-DualMask 3/0 · 500步实验

本实验将后缀对齐权重设为 **3**、新U门稀疏权重设为 **0**。从与历史实验张量一致的重建初态独立训练500次更新，固定余弦周期3651；**并未完成3 epoch训练**。

```text
L = 10 L_S + 2 S_S + 3 L_U + 0 S_U
```

原S0前缀稀疏系数2保留；“U稀疏0”不表示移除了全部稀疏约束。网络、前缀采样、有效后缀W/V归约和数据顺序保持原实现。

## 如何解读

- 相对Clean，3/0在Urban、DCI、Long-DCI双向R@1提高，COCO与Flickr双向下降；DOCCI图→文略低、文→图更高。
- 相对Full，六集12个方向R@1中9项更高；Full仍在Urban、DCI和Long-DCI文→图更高。
- 六集12个R@1等权平均时，相对Clean为+0.426、相对Full为+0.419个百分点；这是追加评测后的描述性汇总，不是预先冻结的选型标准。
- 本轮原先按COCO/Urban及保底约束选型。3/0综合均值69.345虽最高，但COCO图→文59.940低于60.380门槛，因此**未被原规则选中**；原选择仍是1/2。其余四项为用户随后明确要求的追加评测，不应包装成未接触的盲测或追溯改变原选择。
- 本机S0的COCO为60.180/41.240、Urban为86.700/83.600；历史分别为60.580/41.236和87.000/84.200。初态及样本/caption流摘要匹配，但评分差异原因未确定。筛选参考取历史与本机逐方向较高值，未利用偏低S0放宽门槛。
- 单seed、500步的结果不证明统计显著性、全局最优或延长到3651步仍最优。
